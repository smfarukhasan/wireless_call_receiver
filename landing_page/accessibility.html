Accessibility statement

Designed for accessible call control

Wireless Call Receiver's primary purpose is to help blind and visually impaired users handle supported calls without locating an on-screen control.

Who the app supports

The interface provides labeled controls, headings, status announcements, and screen-reader-friendly descriptions. The call-control service is intended for users whose visual impairment makes incoming call interfaces difficult to locate or operate.

AccessibilityService disclosure

When enabled, Wireless Call Receiver can inspect supported incoming call interfaces and perform a targeted Answer or End Call action.

The service can access supported incoming call notifications and visible text, content descriptions, view identifiers, and window structure in supported call interfaces. It can observe configured headset or volume-key events. When requested, it can click a matching call control or tap its exact on-screen bounds. If the user explicitly enables Auto-Answer, a deterministic answer action may run automatically after a supported incoming call is detected.

This information is processed on the device. It is not collected, sold, shared, or transmitted by the developer. The app has no Android Internet permission. Accessibility window processing is restricted to supported calling packages.

Consent and control

Before Android Accessibility Settings opens, the app presents a separate in-app disclosure with Agree and Continue and Not Now. Declining does not prevent access to the rest of the app, although call-control features that depend on Accessibility will remain unavailable. The service can be disabled at any time in Android Settings.

Deterministic automation

Actions follow user-configured rules: a supported incoming call is detected, then a configured hardware event or an explicitly enabled Auto-Answer rule invokes the narrow Answer action. The app does not use generative AI to plan or autonomously choose unrelated device actions.

Known limitations

Android vendors and calling apps can change their call interface, notification actions, key routing, or background behavior. Compatibility is not guaranteed for every device, headset, carrier, or calling app. Wireless Call Receiver must not be relied on for emergency communications.

Accessibility feedback

If a label, focus order, status announcement, contrast level, or supported call flow creates a barrier, report it through the support page. Do not include call content or other sensitive information.
