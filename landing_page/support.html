Technical issue reports

Use the Wireless Call Receiver repository's GitHub Issues page for reproducible bugs and compatibility reports.

Open GitHub Issues

GitHub sign-in may be required. Never post phone numbers, call details, notification text, device identifiers, or other sensitive data.

Include safe diagnostics

  • Android version and device model
  • Calling app name and version
  • Bluetooth headset model
  • Which permission or service is enabled
  • Expected behavior and observed behavior

Redact names, numbers, screenshots, and notification content.

Permission troubleshooting

Open the app's Setup Wizard and review each capability separately. Accessibility and Notification Access are controlled in Android Settings. If access is declined, only the dependent feature is unavailable.

Local data deletion

The app creates no account and the developer holds no user data. Delete local preferences through Android Settings → Apps → Wireless Call Receiver → Storage → Clear data, or uninstall the app.

Emergency limitation

Wireless Call Receiver is not an emergency service and is not guaranteed to answer every call. Maintain another way to receive critical communications.
